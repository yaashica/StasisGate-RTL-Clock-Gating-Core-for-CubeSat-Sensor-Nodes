# StasisGate-RTL-Clock-Gating-Core-for-CubeSat-Sensor-Nodes
StasisGate – Verilog simulation of VLSI clock gating for CubeSat sensor nodes. Implements ICG cells + 3‑state FSM driven by orbit/tasks. Runs entirely in EDA Playground. Cuts simulated dynamic power by 83%. No physical hardware pure RTL simulation.
